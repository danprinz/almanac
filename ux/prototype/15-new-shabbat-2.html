Sanctuary AC — east Set the device Run a script
Cool 24°C Fan: low
Home Assistant has no single call that sets mode, temperature and fan together, so almanac sends two: mode with temperature, then fan. Each is reported on its own — if the unit refuses the fan speed you will see that, and the temperature will still have landed.
Sanctuary AC — west Set the device Run a script
script.ac_west_preset preset: shabbat_pre
This script runs in single mode. If it is already running when the schedule fires, Home Assistant logs “Already running” and returns — the call looks like it worked. almanac checks before calling and will record it as skipped, not as done.
This sets the units once, at 17:23. It does not hold them there — if somebody changes a unit at 18:00, almanac will not put it back. That is what you want here, because stage 2 is about to change them again.
