almanac — UX prototype

dark theme

Twelve static screens, and five more added later for named situations on a real dashboard, built to find out where the rule model in DESIGN.md is hard to render. It is a validation exercise: several of these screens exist because drawing them broke something. The conclusions are in FINDINGS.md — that document is the deliverable, not these pages.

No build step, no framework, no JavaScript beyond a theme switch and an icon sprite. Colours come from Home Assistant's own theme tokens, copied from source with the commit pinned in tokens.css. Nothing here is connected to anything — every number is fixed in the HTML.

Screens 01–12 predate the computed fixture used on 13–17 and still carry hand-written dates, so the two groups disagree about the same schedule — it ends 20:08 here and 20:03 there. Rebasing them is outstanding work; see finding 18 in FINDINGS.md.
